# 🎓 Graduation Angle

A lightweight Flask web application that analyzes a student's academic records and determines whether they can graduate in the current semester.

## Features

* Student login
* Graduation requirement analysis
* Credit requirement check
* Missing required course detection
* Graduation delay warnings

## Tech Stack

* Python
* Flask
* SQLAlchemy
* HTML / CSS / JavaScript

## How It Works

Login → Student Data → Graduation Requirement Analysis → Result


The project uses predefined student records for demonstration and is not connected to a real university academic system.
